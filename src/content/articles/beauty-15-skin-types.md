La plupart des gens ne connaissent pas leur vrai type de peau. L'identifier correctement est la base de soins efficaces.

## Les cinq types

Normal : equilibre. Gras : production excessive de sebum. Sec : production insuffisante. Mixte : zone T grasse, joues normales ou seches. Sensible : reactif, rougeurs.

## Le test du visage nu

Nettoyez votre visage. N'appliquez rien. Attendez une heure. Examinez votre peau. Pressez un mouchoir sur differentes zones. Le mouchoir montre l'huile partout : peau grasse. T-zone seulement : peau mixte. Pas d'huile, sensation de tiraillement : peau seche.

## Deshydratation vs secheresse

La peau seche manque d'huile. La peau deshydratee manque d'eau. Elles peuvent coexister. La solution pour la deshydratation est l'hydratation a base d'eau, pas d'huile.

## Quand votre type change

Avec l'age, les hormones, le climat, les saisons. Reevaluez chaque annee.![beauty-15-skin-types](https://images.unsplash.com/photo-1541752857837-f8a0154fd092)
