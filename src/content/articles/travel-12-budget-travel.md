La plus grande idee recue sur le voyage est qu'il est cher. Il peut l'etre, mais il n'est pas oblige de l'etre. La difference est dans la strategie, pas dans le sacrifice.

## Vols : le plus grand levier

Soyez flexible sur les dates : un vol le mardi ou mercredi est souvent 20-40% moins cher. Soyez flexible sur les aeroports. Reservez 2-6 mois a l'avance. Voyagez avec un bagage a main uniquement.

## Hebergement : le confort sans le cout

Appartements plutot qu'hotels pour les longs sejours. L'emplacement compte plus que le luxe. Petit-dejeuner inclus. Voyagez en saison intermediaire.

## Nourriture : bien manger pour moins

Le dejeuner est le repas de valeur. Faites vos courses au marche. Mangez la ou mangent les habitants. Evitez les minibars.

## Activites : le meilleur est souvent gratuit

La marche est gratuite. Les musees ont des jours gratuits. La nature est toujours gratuite.

La philosophie du voyage economique n'est pas de depenser le moins possible, c'est de depenser intentionnellement.![travel-12-budget-travel](https://images.unsplash.com/photo-1542383578-000e248cde3b)
