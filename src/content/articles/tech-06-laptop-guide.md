Choisir un ordinateur portable est un exercice de surcharge cognitive. Voici un guide clair, sans jargon.

## Les categories

Quotidien (400-700$) : i5 ou Ryzen 5, 8-16 Go RAM, SSD 256-512 Go. Pour la navigation web, les emails et la bureautique.

Ultrabook premium (900-1500$) : Core Ultra ou Ryzen 7, 16 Go RAM, SSD 512 Go-1 To, ecran haute resolution. Pour ceux qui utilisent leur PC toute la journee.

Station creative (1500-2500$) : Pour le montage video, la 3D, le developpement lourd. 32-64 Go RAM, carte graphique dediee.

Etudiant budget (250-400$) : i3 ou Ryzen 3, 8 Go RAM minimum, SSD 128-256 Go.

## Les specs qui comptent

RAM : ne descendez pas en dessous de 8 Go en 2026. Stockage : SSD obligatoire, 256 Go minimum. Ecran : Full HD minimum, IPS pour les angles de vision. Autonomie : 8+ heures en utilisation reelle.

## Le choix du systeme
