La plupart des conseils capillaires supposent que tout le monde a les memes cheveux.

## Connaitre vos cheveux

Type 1 (raides), Type 2 (ondules), Type 3 (boucles), Type 4 (crepus). La porosite et la densite determinent les soins.

## Principes universels

Lavez le cuir chevelu, revitalisez les pointes. Protection thermique obligatoire. Cheveux mouilles fragiles. Pas de lavage quotidien.

## Routines

Type 1 : lavage 1-3 jours, apres-shampooing leger aux pointes. Type 2 : lavage 2-4 jours, creme boucles. Type 3 : lavage 3-7 jours, soin profond hebdomadaire. Type 4 : lavage 7-14 jours, coiffures protectrices, hydratation quotidienne.
